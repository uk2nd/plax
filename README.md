## 今後の実装

・並び替え後に、laneIdが更新されない。既存のロジックがあるため、流用することが期待値。
・タスクとタスクの間に行を追加し、追加した行にレーンを入力すると、「┗」というレーンが作成されてしまう。

・選択モードで全角入力を開始して確定すると、データがStoreに保管されない。半角入力だと正常に保管される。また、F2キーで編集モードに遷移してから、全角入力して確定すると正常に保管される。
・選択モードおよび編集モードで、セルに入力されている既存の文字列を削除して確定すると、Storeのデータが更新されない。

・編集モードでカーソルが頭にある場合、一文字打つとカーソルがお尻に移動してしまう

複数選択
---
1. Shift + ↓ / Shift + ↑ で複数行選択

キーボードで矢印キーを使いながらShiftキーを押すと、行が選択範囲に追加される
通常の矢印キー（Shiftなし）を押すと選択がクリアされる

2. Shift + クリックで範囲選択

最初にカーソルが当たっていた行から、Shiftを押しながらクリックした行までの全ての行が選択される

3. Ctrl + クリックで追加選択

現在の選択範囲を保持したまま、新しい行を選択に追加できる
既に選択されている行をCtrl+クリックすると選択から除外される

4. 視覚的なハイライト

選択された行は青色の背景（bg-blue-100）でハイライト表示される
